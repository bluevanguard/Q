# هنرجو یار v3 — مسیر آموزشی تار و سه‌تار

این نسخه برای GitHub Pages/PWA آماده شده و پروژه Android Studio آن نیز همراه فایل‌ها قرار دارد.

## تغییرات v3
- تیونر کروماتیک با نمایش نت، فرکانس، سنت، دیز/بمل و فاصله
- توضیح پرده، نیم‌پرده و تفاوت پرده‌بندی سازهای ایرانی
- تصویر اختصاصی برداری تار و سه‌تار
- مسیر آموزشی مرحله‌ای از مبانی موسیقی تا ریتم‌خوانی، وزن‌خوانی و ورود به ردیف
- درس‌های بازشونده و بخش استادان/منابع
- شاهد و جمله تمرینی اختصاصی برای هر دستگاه در نسخه آموزشی
- بدون نمایش برچسب یا متن «هوش مصنوعی» در رابط برنامه

## PDF آموزشی
پس از دریافت PDF شما، درس‌ها را با ساختار آن تطبیق می‌دهیم و مطالب را به صورت خلاصه و بازنویسی آموزشی وارد می‌کنیم؛ متن کامل آثار دارای حق نشر یا نت کامل قطعات بدون مجوز کپی نمی‌شود.
